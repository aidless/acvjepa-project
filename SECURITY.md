# Security Policy

## Supported Versions

This is a personal research project; only the latest commit on the default branch is supported.

## Reporting a Vulnerability

If you discover a security issue, please **open a private GitHub security advisory** via this repository's **Security → Report a vulnerability** button (https://github.com/aidless/acvjepa-project/security/advisories/new), or contact the maintainer through their GitHub profile. Please do not open a public issue for exploit details.

You can expect an initial response within 7 days.
