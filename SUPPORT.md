# Support

## Where to ask

| I want to... | Do this |
|---|---|
| Report a bug | [Open an issue](https://github.com/acvjepa-project/issues/new/choose) using the bug template |
| Suggest a feature | [Open an issue](https://github.com/acvjepa-project/issues/new/choose) using the feature template |
| Report a security problem | **Private channel** in [SECURITY.md](SECURITY.md) — do not open a public issue |
| Ask how to use this | [Open a discussion](https://github.com/acvjepa-project/discussions) if enabled, otherwise an issue |

## Before you report a bug

- Check whether the repository has a CI badge or a stated verification command; if it
  does, run it and include the output. A failure with output is usually answered faster.
- Include the exact error text, not a paraphrase.
- Include the version or commit you tested against.

## What to expect

This is an independently maintained repository. A human-readable reply is best effort,
not an SLA. Feature requests and research questions may take longer, and proposals
that need new experiments are usually declined rather than promised.

## Scope note

Reproduction questions are the most welcome kind here. Questions about research direction, novelty, or unpublished results are not answered in issue threads; the pre-registration documents in this repository already state what was decided and why.
